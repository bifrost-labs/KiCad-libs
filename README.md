# KiCad symbols and footprints

Commonly used symbols and footprints used by bifrost-labs.io

## Installation

Download zip from github repo, or git clone the repo into your local
KiCad 3rd party location (TODO: create and publish as a proper extension package):

- macOS: $HOME/Documents/KiCad/10.0/3rdparty
- linux: TBD
- Windows: $env:USERPROFILE\Documents\KiCad\10.0\3rdparty (or redirected to
$env:USERPROFILE\OneDrive\Documents\KiCad\10.0\3rdparty)

e.g.:
```bash
cd $HOME/Documents/KiCad/10.0/
git clone https://github.com/bifrost-labs/KiCad-libs.git 3rdparty/
```
